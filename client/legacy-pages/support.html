How to become a host

Start hosting from your Profile, available in the sidebar on both desktop and mobile.

  1. Open your Profile from the sidebar.
  2. Find and select Become a Host.
  3. You will be redirected to create a Host Account.
  4. Complete the Host Account setup.
☾

How to turn on dark mode

Keep VaRoom comfortable on your eyes with dark mode.

  1. Open your Profile.
  2. Go to Settings.
  3. Open Display Preferences.
  4. Find Dark Mode and turn it on.
◌

How to view as marketplace

Switch to Marketplace view to browse listings in a marketplace format.

  1. Open Explore.
  2. Find the option to view as Marketplace.
  3. Select View as Marketplace.
  4. Browse listings in Marketplace format.
＋

How to add a listing

Host tools become available after you create a Host Account.

  1. HOST — DESKTOP: Find Add Listing in desktop navigation and select it.
  2. HOST — MOBILE: Select the + button next to Search at the top.
  3. NOT A HOST YET: Create a Host Account first.
⚑

How to report a listing

Report a listing from the listing itself or the host's profile.

  1. Open the exact listing you want to report.
  2. Open the three-dot menu (⋯) at the top-right.
  3. Select Report and choose a reason.
  4. Write a custom reason if needed, then submit.

The report is handed over to the VaRoom Support team for review.

⇄

How to switch or add an account

Add an existing account through your profile menu.

  1. Open your Profile and select your profile photo.
  2. Select the dropdown arrow, then Add an existing account.
  3. Sign in; the account is added to the account switcher.
  4. Switch accounts from the profile dropdown or Settings → Login & Account.

This feature is being finalized, so this guidance may be updated.
